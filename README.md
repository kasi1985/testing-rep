# testing-rep

This repository includes Git hook support for AI-generated code tracking.

- `.github/copilot-instructions.md` defines AI tagging conventions.
- `.git/hooks/pre-commit` counts AI-generated lines and strips tag markers before commit.
- `.git/hooks/commit-msg` appends `AI-Lines-Of-Code: <count>` to the commit message when AI-generated lines are present.

## Testing locally

Quick steps to try the AI-tagging and hooks locally:

1. Create a sample file with AI tags, for example `sample_ai.js`:

```js
function aiGenerated() {
	console.log('This line was generated by AI');
}
```

2. Stage and commit the file (the hooks run automatically):

```bash
git add sample_ai.js
git commit -m "Add sample AI code"
```

3. Verify the commit message includes the AI metrics footer added by the `commit-msg` hook:

```bash
git log -1 --pretty=%B
```

Notes:
- The pre-commit hook strips the START/END tags before the commit is finalized and writes a temporary AI line count to `.git/ai_lines_count.tmp`.
- The `commit-msg` hook reads that temp file and appends `AI-Lines-Of-Code: <count>` to the commit message.
- Pull requests are also tracked by CI via `.github/workflows/ai-metrics.yml` which summarizes AI vs human lines in a PR comment.
